# U. Rajya Laxmi | Portfolio

A responsive student portfolio built with semantic HTML, custom CSS, Bootstrap 5, and plain JavaScript. Its sections follow the resume headings: Objective, Education, Skills, Experience, Projects, Certifications, and Extra Curricular Activities.

## Add your profile photo

Place a portrait image at `assets/profile.jpg`. The home-page portrait frame is already sized and styled for it. A designed initials placeholder appears until the image is added, so the page still looks complete in the meantime. Use a clear, well-lit portrait; a vertical image works best.

## Run locally

Open `index.html` in a browser, or use the Live Server extension in VS Code. Bootstrap and Bootstrap Icons are loaded from CDNs, so an internet connection is needed for those external assets.

## Interactive features

- Light and dark themes, with the choice saved in the browser.
- A responsive mobile navigation menu.
- Contact form validation with accessible, field-specific error messages. A valid message opens as a prefilled Gmail draft for the visitor to review and send; this static site does not send or store messages.
- Skip link, keyboard focus styles, and reduced-motion support.

## Personalize before publishing

Check the email address, phone number, social profiles, project details, and dates in `index.html`. The resume details supplied for this portfolio are used as provided; update any project links or descriptions to match the version you want to share.

## Publish with GitHub Pages

Push the repository to GitHub, then open **Settings → Pages** and select the branch and root folder containing `index.html`. After GitHub Pages finishes publishing, use the URL shown in that settings page as the live portfolio link.
